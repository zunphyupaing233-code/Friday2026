# FRIDAY Portfolio 2026 — Vercel Ready

Static portfolio website for Lu Oo Maung (FRIDAY).

## Structure
- `index.html`
- `styles.css`
- `script.js`
- `assets/`

No build step is required. Upload the contents of this folder (or the ZIP) directly to Vercel as a static project.

## Curation
The portfolio order is curated by visual hierarchy and project type:
1. Featured / Selected Works
2. Motion Works
3. Portfolio 2026 categories
4. About + Skills
5. Contact

All supplied JPG portfolio boards are 1920×1080 (16:9). GIF works are 800×450 (16:9). The site uses intrinsic sizing and `object-fit: contain` rather than stretching or hard-cropping artwork.
